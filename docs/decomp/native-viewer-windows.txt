COMET CRASH - NATIVE VIEWER AND SKIRMISH PREVIEW

Includes a native C++/OpenGL model viewer and a limited skirmish preview.
It contains no Comet Crash game files.

Extract the ZIP, then drag your extracted NPEB00142 game folder onto
OPEN_VIEWER.cmd. The launcher finds USRDIR/data beneath that folder.
It also accepts the USRDIR or data folder directly.

Controls:
  Left/right arrows: previous/next arena model
  Left mouse drag: orbit camera
  Mouse wheel: zoom
  W: wireframe
  R: reset camera
  Escape: quit

To inspect the static rock-comet geometry from a command prompt:
  comet_native.exe --assets "D:\CometCrash\USRDIR\data" --object models/care/cometRock_03/cometRock.obj --viewer

A GPU/driver supporting framebuffer objects, floating-point render targets
and vertex buffers is required. The viewer reports an exact error if graphics
initialization or an original asset load fails.

Gameplay, missions, HUD, original material shaders, audio, saves and multiplayer
remain to be recovered and connected. This executable must not be described
as a finished Comet Crash port.

NATIVE PREVIEW SKIRMISH
----------------------
The same package now includes OPEN_SKIRMISH.cmd and native-skirmish.cfg.
Drag your extracted game folder onto OPEN_SKIRMISH.cmd. No original map
extraction is needed for this mode. Original model/texture assets are required.

The preview starts paused with a human player and an automatic opponent.
The cursor starts on your base. Press Right, 7, B to build a nearby factory.
Press P to run, and hold D to release produced units. Press 3 to select Tesla
construction, then B on an empty nearby cell to build a working defense.
Arrows move the build cursor. Tab cycles human players only. F2 restores the
launch checkpoint. Base-counter depletion produces victory/defeat and freezes
the preview. Restart returns paused.

This is a configurable native skirmish, using recovered simulation components
and native preview rules. Original campaign/AI, player craft/aircraft, additional
weapons, authentic economy/audio and complete original presentation remain open.

GAMEPAD (SDL standardized labels)
Left stick/D-pad: cursor; A: build; LB/RB: structure type; X/R2: hold release.
Y: factory mode; L3: release type; R3: human player; Start: play/pause; Back: restart.
B: cancel. Release buttons/center sticks after pause, reconnect or restart.
Disconnect/focus loss pauses and cancels held input. One active controller.

F3: opt-in pilot preview. P/Start runs; IJKL or left stick moves the ship.
The build cell follows the ship. F2 returns it to the human base.
Pilot position/velocity uses recovered free-flight arithmetic; bounds and heading
remain native preview rules. Original collision/action gates remain open.
