# Comet Crash 1 PC Port

Windows-native static-recompilation project for **Comet Crash** (PS3 title **NPEB00142**, target copy **v1.00**) using the open-source `ps3recomp` ecosystem.

## Objective

Boot and run the original game code natively on Windows, preserve controller gameplay, then add first-class mouse/keyboard controls and safe PC display improvements.

## Continuity

This repository is the canonical project record. A fresh work session should read **`CONTINUITY.md` first**, then **`NEXT.md`**, **`DECISIONS.md`**, and the supporting files referenced there.

## Repository boundary

This repository must not contain or redistribute proprietary Comet Crash binaries/assets, Sony SDK material, PKG/RAP/RIF files, decrypted EBOOT/ELF files, or extracted copyrighted game data. Users supply their own legally obtained game files locally.

Generated metadata that does not embed copyrighted game content, original port code, build scripts, compatibility reports, and address/signature-based patches may be stored here.
